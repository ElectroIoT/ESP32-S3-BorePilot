BorePilot - schematic build guide (EasyEDA Pro web)

Draw the schematic by hand, page by page. Every part has its LCSC number to search, every wire has a colour, every page has a check list. Progress is saved in this browser.

Plan stage. Nets come from PLAN.md, not from a finished schematic. Pin names and orders must be checked against the EasyEDA symbols and datasheets (SGM2212, SRD relay, USB-C, PZEM, displays). 230 V AC on J2, J3, U2, J4, J5: engineer review before mains power.

0. Setup in EasyEDA Pro

1. Open EasyEDA Pro (web). Create the project BorePilot (Project → New). Inside it create one Schematic and one PCB (empty for now).
2. In the schematic, add 6 pages with the sheet names above (right-click the schematic in the left Project panel → New Schematic Page). You can start with 5 and skip the cover.
3. Set the grid to 5 or 10 (snap on) so wires land on pins. Set the sheet size to A3.
4. To place a part: open the library search, type the LCSC part number (C#) given in the table (for example C3294699), pick the result with the same MPN and place it. The symbol, footprint and 3D model are then tied to the LCSC part.
5. Set each part's Designator to the Ref in the table (U1, J2, R3 ...) and its Value. The Ref numbers match the BOM pages.
6. Use Net Label for every connection that leaves a page or goes more than a few cm; use Power Port symbols for GND, +5V, +3V3 (type the same names everywhere). Net label names are case-sensitive.
7. Mark optional/DNP parts with the 'Not in BOM' / 'Not placed' attribute so the final BOM leaves them out.
8. Save often. After each page run Design → Check ERC (design rule check for schematics) and fix every warning before moving on.

2. Wire in this order

1. Place J2 (AC in) and J3 (AC tap). Pin 1 of both = L, pin 2 = N. Add net labels L and N on them.
2. Place U2 HLK-5M05. Wire its AC pins to L and N. Add net label +5V_HLK on +Vo and a GND symbol on -Vo.
3. Place D4 and D5 (SS34B). D4: anode to +5V_HLK, cathode to +5V. D5: anode to VBUS, cathode to +5V. Cathode = the end with the bar.
4. Place C1 (470 uF) between +5V and GND. Observe polarity: + to +5V.
5. Place C6 (10 uF), C15 (100 nF on +5V_HLK) and C5 (10 uF) on the +5V rail to GND.
6. Place U3 SGM2212-3.3: VIN to +5V, GND to GND, VOUT to +3V3. Add C2 (10 uF) at VIN and C3 (10 uF) at VOUT. Check the symbol's pin names; do not assume the pin order.
7. Place J1 USB-C (C165948). VBUS pins (A4, B9, A9, B4) to VBUS; GND pins (A1, B12, A12, B1) and shield pins to GND.
8. CC1 (A5) to R1 5.1 k to GND; CC2 (B5) to R2 5.1 k to GND. SBU pins (A8, B8) left unconnected (mark No-Connect).
9. D+ pins (A6 and B6 together) and D- pins (A7 and B7 together) go to U4 USBLC6, then net labels USB_DP and USB_DN. U4 VBUS pin to VBUS, GND to GND.
10. Place C7 (10 uF) and C11 (100 nF) on VBUS to GND.
