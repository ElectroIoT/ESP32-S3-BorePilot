Page 1 - Power and USB

Circuit view

How the mains reaches the HLK module. The red dashed area is the 230 V side. Colours: orange = 5 V, yellow = 3.3 V, grey = GND, green = GPIO, pink = display / I2C, purple = USB, cyan = UART, red / blue = mains.

  1. J2 pin 1 is L, pin 2 is N. J3 repeats L and N for the PZEM voltage input.
  2. U2 turns it into isolated 5 V (+5V_HLK) on the low-voltage side.
  3. There is no fuse or varistor on the board: your panel breaker must protect it.

3 parts, page 1

Hazardous side. No fuse or varistor on board (owner decision): protect upstream.

Circuit view

How 5 V and 3.3 V are made. Colours: orange = 5 V, yellow = 3.3 V, grey = GND, green = GPIO, pink = display / I2C, purple = USB, cyan = UART, red / blue = mains.

  1. The HLK output and USB VBUS each go through a Schottky diode into the common +5V rail.
  2. C1, C5, C6 smooth the rail; C2 sits on the LDO input.
  3. U3 makes +3V3, with C3 at its output.

9 parts, page 1

HLK-5M05 and USB VBUS OR-ed through Schottky diodes to +5V, then SGM2212 LDO to +3V3.

Circuit view

How USB-C is wired. Colours: orange = 5 V, yellow = 3.3 V, grey = GND, green = GPIO, pink = display / I2C, purple = USB, cyan = UART, red / blue = mains.

  1. CC1 and CC2 each have a 5.1 k resistor to GND so a USB-C cable gives 5 V.
  2. D+ pins A6/B6 and D- pins A7/B7 are tied together, go through U4, then on to GPIO20 / GPIO19.
  3. VBUS feeds D5 (page 1) and U4.

6 parts, page 1

C165948 USB-C, native USB on GPIO19/20, 5.1 k CC resistors, ESD part.

Page 2 - ESP32-S3 core

Circuit view

What the ESP32 needs around it. Colours: orange = 5 V, yellow = 3.3 V, grey = GND, green = GPIO, pink = display / I2C, purple = USB, cyan = UART, red / blue = mains.

  1. 3V3 and GND power the module; C4, C9, C10 decouple it.

Page 3 - Relays and mains contacts

Relay circuit view: one picture per channel

How one channel really works: GPIO, MOSFET, relay coil, with the contacts on the mains side. Wire colours: orange = +5V, green = signals, brown = relay contacts, grey = GND.

  1. Idle: the GPIO is low and the 100 k resistor holds the gate low, so the MOSFET is off and no current flows in the coil. COM is connected to NC.
  2. ON: the ESP32 pulls the RLYn flag high. The MOSFET turns on and pulls the RLYn_D node to GND. Current flows +5V, coil, MOSFET, GND, and the relay switches: COM is now connected to NO.
  3. LED: +5V, resistor, LED, RLYn_D. It lights only while the MOSFET is on.
  4. Diode: when the MOSFET switches off the coil kicks voltage back. The diode (bar on the +5V side) gives that current a loop so the MOSFET is not damaged.
  5. Net flags that must exist: RLYn on the MOSFET gate (from page 2) and RLYn_D on the coil / diode / drain node. Without them the relay never switches and the LED never lights.

16 parts, page 3

Two SPDT relays, COM/NO/NC on 5.08 mm terminals, low-side AO3400A drivers.

Page 4 - PZEM link and I/O

Circuit view

How the PZEM module is connected. Colours: orange = 5 V, yellow = 3.3 V, grey = GND, green = GPIO, pink = display / I2C, purple = USB, cyan = UART, red / blue = mains.

  1. +5V and GND power the module from the J6 header.
  2. GPIO17 (TX) drives the PZEM RX pin directly (3.3 V is enough).
  3. PZEM TX returns through R16 and R4 which divide it down for GPIO18 (RX).

4 parts, page 4

UART1 header for the external PZEM-004T v3 module.

Circuit view

Buttons, LEDs, float inputs and the optional buzzer. Colours: orange = 5 V, yellow = 3.3 V, grey = GND, green = GPIO, pink = display / I2C, purple = USB, cyan = UART, red / blue = mains.

  1. Each button pulls its GPIO to GND when pressed.
  2. LED1 is the power LED (from +3V3); LED2 follows GPIO16.
  3. Floats connect between IN1 / IN2 and GND. The buzzer parts are optional.

17 parts, page 4

START, STOP, MENU, status LEDs, optional buzzer, float inputs, spare GPIO.
