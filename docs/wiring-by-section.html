BorePilot - wiring by section

One pin-to-net diagram per section, grouped under the same 5 schematic pages as the schematic guide. Draw each box as a part, then connect the pins that share a net.

Plan stage. Planned nets from PLAN.md, not a finished schematic. Each box lists pins by the names planned for the symbol (module pin numbers where I know them: USBLC6, PCA9306, 74AHCT125, J9 header; others by function). Check every pin name against the EasyEDA symbol and datasheet (SGM2212, SRD relay, USB-C, PZEM, display modules). 230 V AC on J2, J3, U2, J4, J5: engineer review before mains power.
