BorePilot - connection map

ESP32-S3 pump controller: mains and USB power, relays with COM/NO/NC, PZEM link, three display options, wireless tank unit. Grouped in the same eight sections as the BOM page.

Plan stage. This is a block-level map of the planned design from PLAN.md. No schematic or PCB exists and nothing has been built or tested. Mains is involved: engineer review before any mains power.

Wiring order, section by section

Power

  1. J2 L, N -> U2 AC pins, and J3 (AC tap).
  2. U2 +Vo -> D4 anode; D4 cathode -> +5V. U2 -Vo -> GND.
  3. J1 VBUS -> D5 anode; D5 cathode -> +5V.
  4. +5V -> C1 470 uF, C6, C2, U3 VIN. U3 VOUT -> +3V3 -> C3, C4.

USB

  1. J1 CC1 -> R1 -> GND, CC2 -> R2 -> GND.
  2. J1 D+ pins (A6, B6) -> U4 -> GPIO20; D- pins (A7, B7) -> U4 -> GPIO19.
  3. Shield -> GND (decide direct or 1 M || 100 nF).

Relays

  1. GPIO4 -> Q1 gate (+ R18 to GND); Q1 drain -> K1 coil- (+ D1 to +5V); K1 coil+ -> +5V.
  2. GPIO5 -> Q2 gate (+ R19); Q2 drain -> K2 coil-; same as above.
  3. K1/K2 COM, NO, NC -> J4/J5 pins 1, 2, 3 (mains side of the slot).
  4. LED3/LED4 + R10/R11 between +5V and the Q drains.

PZEM

  1. J6: +5V, GND, ESP TX (GPIO17) -> PZEM RX.
  2. PZEM TX -> R16 4.7 k -> GPIO18, R4 10 k from GPIO18 to GND.

Displays

  1. J8 OLED: +3V3, GND, SDA GPIO8, SCL GPIO9, R12/R13 pull-ups.
  2. J7 16x2: GPIO8/9 -> U5 low side; U5 high side -> J7 SDA/SCL, +5V.
  3. J9 12864: GPIO10/11/12/14 -> U6 -> J9 pins 4, 5, 6, 17. SJ1 bridges J9 pin 15 to GND.
  4. Q3 gate GPIO13 + R20; drain -> J9 pin 20 (BLK). RV2 on V0/VOUT.

UI / IO

  1. SW3/SW4/SW5 from GPIO1/2/6 to GND (internal pull-ups).
  2. LED1 + R8 on +3V3; LED2 + R9 from GPIO16.
  3. J10/J11 pin 1 -> GPIO39/40, pin 2 -> GND.
  4. BZ1 + Q4 + D3 on GPIO15 (optional).
